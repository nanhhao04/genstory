# Thư mục Dữ liệu Tĩnh (Static)

Thư mục này dùng để lưu trữ các tài nguyên tĩnh được chia sẻ cho cả giao diện người dùng (UI) và máy chủ (Backend).

## Các thư mục con
- **fonts/**: Lưu trữ các file font TrueType (.ttf) dùng cho việc xuất bản PDF tiếng Việt (như font NotoSans).
- **exports/**: Thư mục chứa các file PDF đã được tạo ra và sẵn sàng cho việc tải về.
- **images/**: Lưu các tài nguyên hình ảnh cố định của hệ thống.
